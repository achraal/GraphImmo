# housing-recommendation-neo4j
Real estate housing recommendation system using Neo4j graph database, FastAPI, GraphQL (Strawberry) and React.

# Real Estate Recommendation System

This project is a real estate housing recommendation system based on a graph-oriented approach.

It uses Neo4j to model users, properties, preferences, and relationships between them in order to generate personalized housing recommendations.

## Tech Stack
- Backend: FastAPI (Python)
- API: GraphQL with Strawberry
- Database: Neo4j (Graph Database)
- Frontend: React
- Query Language: Cypher

## Features
- Graph-based modeling of users and properties
- Personalized housing recommendations
- GraphQL API for flexible data querying
- Interactive frontend for search and recommendations

## Use Case
This project demonstrates how graph databases can be used to build intelligent recommendation systems in the real estate domain.

        React (Apollo Client)
                   ↓
        GraphQL API (/graphql)
                   ↓
        FastAPI + Strawberry
                   ↓
        Neo4j (Cypher Queries)
